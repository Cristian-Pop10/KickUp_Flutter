# ⚽ KickUp

**KickUp** es una aplicación móvil desarrollada con **Flutter** y **Firebase** que permite **reservar pistas de fútbol y organizar partidos en zonas rurales**, conectando a jugadores y administradores de pistas en una misma plataforma.

---

## 🚀 Características principales

- 🔐 **Autenticación de usuarios** con Firebase Auth (registro e inicio de sesión).
- 📍 **Búsqueda de pistas** por ubicación y disponibilidad.
- 🗓️ **Sistema de reservas** en tiempo real con Firestore.
- 📢 **Creación y gestión de partidos** públicos o privados.
- 🔔 **Notificaciones automáticas** para confirmar reservas o unirse a partidos.
- 🧭 **Interfaz intuitiva** optimizada para Android e iOS.

---

## 🧰 Tecnologías utilizadas

| Componente | Tecnología |
|-------------|-------------|
| **Frontend** | Flutter (Dart) |
| **Backend** | Firebase Firestore, Firebase Auth, Firebase Storage |
| **Hosting / Datos** | Firebase Cloud |
| **Gestión de estado** | Provider |
| **Diseño UI** | Material Design 3 |
